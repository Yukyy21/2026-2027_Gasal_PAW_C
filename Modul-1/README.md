# Modul 1 — Dasar PHP

Rangkuman materi yang dikerjakan pada Modul 1.

## Menampilkan Teks

- **Tugas-1.php** — `Hello world` dengan *non-embedded script*, kode PHP berada
  di luar HTML.
- **Tugas-2.php** — `Hello world` dengan *embedded script*, kode PHP ditulis
  di dalam tag HTML.
- **Tugas-3.php** — `Hello world` dengan *embedded script*.

## Variabel

- **Tugas-4.php** — Variabel dan sensitivitas huruf besar: `$color` ("silver")
  dan `$COLOR` ("white").
- **Tugas-5.php** — Menyimpan teks ke variabel lalu mencetaknya (`$greeting`).
- **Tugas-6.php** — Menggabungkan string dengan operator titik (`.`).

## Operator

- **Tugas-7.php** — Operator aritmetika, menjumlahkan `$x = 5` dan `$y = 7`.

## Fungsi String

- **Tugas-8.php** — `strlen()` menghitung panjang string.
- **Tugas-9.php** — `str_word_count()` menghitung jumlah kata.
- **Tugas-10.php** — `strrev()` membalik string.
- **Tugas-11.php** — `strpos()` mencari posisi sebuah kata dalam string.
- **Tugas-12.php** — `str_replace()` mengganti kata dalam string.

## Fungsi

- **Tugas-13.php** — Fungsi tanpa parameter.
- **Tugas-14.php** — Fungsi dengan satu parameter.
- **Tugas-15.php** — Fungsi dengan dua parameter.
- **Tugas-16.php** — Fungsi dengan nilai default parameter.
- **Tugas-17.php** — Fungsi yang melakukan operasi pada parameter.
